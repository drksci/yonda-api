# Real-Time Narrative Synthesis

The narrative synthesizer takes speed, themes, and audience mode into account:

- **Speed > 100 km/h**: Generates short 15-30 second soundbites to avoid driver distraction.
- **Speed < 50 km/h**: Generates rich 60-90 second RadioLab-style documentaries.
- **Audience Mode**: Tailors language complexity and content suitability (`family`, `couple`, `mature`).
